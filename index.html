在手机上继续你的远程 AI 编程

Roamtty 是为触屏设计的 SSH 终端。用 tmux 保持会话、用 mosh 穿越网络切换，在通勤路上查看每个 Agent 的进度，直接在会话卡片上批准它的操作或接着追问，再打开终端或文件细看。

为手机上的远程开发而做

AI 工具运行在你的服务器上，Roamtty 让你在手机上随时接上它们。

AI Agent 会话

选 Agent、主机和起始文件夹即可开工，可选只读、普通或 YOLO 权限。会话按待确认 / 运行中 / 已完成分组，卡片显示任务、正在执行的命令和结果摘要，可直接点“允许”或“追问”。

tmux 会话保持

每个会话对应独立的远端 tmux 会话。断网、锁屏或关闭应用后任务继续运行，回来时自动重新附着。

mosh 漫游

主机装有 mosh 时优先走 UDP，在 Wi-Fi 和蜂窝网络之间切换也不断线；没有回应时自动回退到 SSH。tmux 和 mosh 都可在应用内一键安装。

为触屏设计的终端

双击发送 Tab，左右滑动发送方向键；按住小幽灵弹出按当前程序定制的快捷键环（Claude Code、Codex、Grok、Gemini CLI 各有一套）。双指缩放字号，长按选择复制或拖动光标。

SFTP 文件

浏览服务器文件，预览代码（语法高亮）、Markdown 和图片；上传、下载、重命名、删除，或把手机里的图片路径直接插入终端交给 Agent。

主机监控

实时查看 CPU、内存、磁盘、网络、GPU 和占用最高的进程，确认 Agent 跑的测试或构建是否卡住。

在任何网络连回家

配合 Tailscale（或自建 Headscale 与 DERP 中继）即可从蜂窝网络连回家里或公司的电脑，服务器不必暴露在公网。查看组网教程

安全默认

首次连接核对 SHA-256 主机指纹，指纹变化直接阻止连接；密码只在你勾选后加密保存，私钥口令从不落盘。

Linux、macOS、Windows

支持 OpenSSH 的 Linux、macOS、BSD 与 Windows 主机，自动识别系统；Windows 上用 psmux 保持会话、PowerShell 读取目录与监控。

看看实际界面

以下均为 Android 版的实际界面，连接的是演示服务器和示例项目。

Android 与 iPhone，同一套体验

两个版本功能保持一致，界面默认简体中文，可切换 English。

Android

需要 Android 8.0 及以上

  • 凭据由 Android Keystore 加密保存
  • 前台服务在后台保持你打开的连接，最后一个连接断开即释放
  • 可从系统分享直接上传图片

iPhone

需要 iOS 16 及以上

  • 凭据保存在仅限本设备的钥匙串中
  • 下载的文件可在“文件”App 中查看
  • 从分享菜单把照片、文件和文本发送给 Roamtty 上传

你的服务器，只属于你

Roamtty 没有后端服务器。主机、凭据和设置只保存在你的设备上，连接只发往你添加的服务器。

  • 无需注册账号
  • 无广告、无统计分析、无崩溃上报
  • 首次连接核对 SHA-256 指纹，指纹变化直接阻止连接
  • 密码仅在你勾选后加密保存，私钥口令从不保存
  • 终端内容只存在于内存中
  • 一次购买，没有内购和订阅
