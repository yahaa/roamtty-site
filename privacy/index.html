Roamtty 隐私政策

生效日期：2026-10-26

Roamtty 是一款 SSH 终端客户端，提供 Android 版与 iOS 版（以下合称“应用”）。我们（Roamtty 开发者）不运营任何应用后端服务器，不要求注册账号，不会自动收集或上传你的个人数据，也不会出售你的个人数据；你主动联系支持或分享报告时，相关内容会发送给你选择的接收方。本政策适用于从 Google Play 或 App Store 获取的 Roamtty，以及网站 roamtty.com。

摘要

  • 没有账号或广告，不集成第三方统计分析或崩溃上报 SDK，也不会自动上传诊断报告。
  • 主机配置、凭据和设置只保存在你的设备上；凭据由系统密钥库加密保护。
  • 终端、文件和远程桌面数据发往你自己添加的服务器；安装桌面插件时还可能连接下文列出的下载服务。开发者不会自动收到你的会话内容；你主动联系支持或分享报告时，会向你选择的接收方发送相应内容。

应用在设备上保存的数据

以下数据只保存在你的设备中，仅供应用自身功能使用：

  • 主机信息：名称、地址、端口、用户名、认证方式、会话模式、检测到的远端系统类型与已安装的 tmux / mosh 状态。
  • 凭据：密码仅在你选择保存时写入；导入的私钥在保存使用私钥认证的主机时写入，没有单独的“不保存私钥”选项。私钥口令从不保存。
    • Android：密码和私钥使用 Android Keystore 中不可导出的密钥以 AES-256-GCM 加密，密文保存在本机 Room 数据库中。
    • iOS：密码和私钥保存在系统钥匙串中，访问级别为“仅限本设备、首次解锁后可用”，不会随备份或设备迁移转移到其他设备。
  • 服务器信任记录：你确认信任的服务器公钥及其算法，按服务器地址和端口保存；应用由公钥计算指纹，用于防止中间人攻击。同一地址和端口的主机配置共享此记录。
  • 会话记录：每台主机最多 8 条会话的 ID、对应主机、模式、标题、远端 tmux 会话名和会话序号，用于应用重启后恢复会话列表。不包含终端内容。
  • 最近使用顺序（Android）：仅保存最近打开的主机和会话 ID 的顺序，用于列表排序；删除对应条目后清理，不记录打开时间或操作内容。
  • Agent 状态摘要（iOS）：最近的 Agent 状态、工具和命令摘要、工作目录、最近提示词的前 200 个字符及回复的前 400 个字符，保存在本机偏好存储中，以便重新打开应用后显示会话卡片。移除对应会话时清除这些摘要；卸载应用会删除本机偏好存储。
  • 本机诊断（iOS）：应用保留最多 400 条运行事件日志和 20 份 iOS MetricKit 指标或诊断报告，供你排查崩溃、卡顿和内存问题。报告只保存在设备上，不会自动上传。你可以在“关于”页面主动通过系统分享菜单发送给自己选择的接收方；分享前请检查报告内容。卸载应用会删除这些本机文件。
  • 偏好设置：语言、主题、字体（含你导入的自定义字体文件）、字号、操作栏和下载目录等设置。
  • 你传输的文件（iOS）：从服务器下载的文件保存在应用的“文稿”目录，可在“文件”App 的“我的 iPhone › Roamtty”中查看和删除；通过系统分享发送给应用的图片、文件和文本暂存在应用容器中，直到你上传或删除。Android 上下载的文件保存在你通过系统文件选择器指定的位置。

除上述 Agent 状态摘要外，终端输出、输入内容和编辑草稿只存在于内存中，不写入磁盘。Android 版关闭了系统备份与设备迁移；iOS 版把主机数据库排除在 iCloud 和电脑备份之外，钥匙串中的凭据也不会进入备份。你下载到 iOS“文稿”目录的文件与其他用户文件一样，可能包含在你自己的设备备份中。

iOS 远程桌面

启用远程桌面后，屏幕画面、远端声音及键盘/指针操作在设备与所选主机之间通过 SSH 或经认证的加密 UDP 传输，不经过 Roamtty 中继。声音仅用于播放，不录制手机麦克风。应用会将每台主机最近的桌面画面保存为本地 JPEG 缩略图，用于会话卡片；它可能包含屏幕上的敏感信息，断开连接后仍保留，删除主机时移除，卸载应用也会删除。这些缩略图可能包含在你自己的设备备份中。显示器、音量/声音、画质和控制方式等偏好保存在本机。

只有你点按发送或获取剪贴板时，文本才会在手机系统剪贴板与远端剪贴板之间复制；应用不自动持续同步剪贴板。远端系统及其他具有剪贴板权限的应用可能读取其系统剪贴板。

你主动安装或更新桌面插件时，应用可能由手机或远端主机通过 HTTPS 从 GitHub Releases 下载 Roamtty 桌面插件，并从 Cisco 下载 OpenH264。相应服务商会接收下载请求的 IP 地址及常规网络请求信息，并按各自政策处理。插件安装在你选择的远端计算机上，不会将下载的可执行代码安装到 iOS 应用中。

网络连接

  • 除你主动发起的插件下载外，应用连接到你自己添加的服务器：SSH（TCP）、mosh（UDP）、远程桌面的加密传输，以及用于显示在线状态和延迟的 TCP 连通性检测。iOS 在连接局域网内的主机前会请求“本地网络”权限。
  • SSH 与 mosh 连接均加密传输；应用不发起明文 HTTP 请求（远程桌面插件的下载只走 HTTPS）。点按终端中的链接时，链接由系统浏览器或对应的应用打开。
  • 连接时，应用会在远端执行只读操作：识别远端系统、检查 tmux / mosh 是否可用（结果保存在本机的主机信息中），以及读取远端 shell 历史文件作为“常用命令”。常用命令只缓存于会话的内存状态，断开后仍可能用于查看，不写入应用持久化存储，进程结束后不保留。主机详情页的监控数据（CPU、内存、磁盘、网络、进程）同样只在内存中显示。其他远端操作只在你主动发起时执行，例如安装 tmux / mosh，或通过 SFTP 上传、下载文件。
  • 从应用启动 Claude Code、Codex 或 Grok 时（Windows 起始目录除外），应用会在远端写入用于显示 Agent 状态的 hook 文件：~/.roamtty/agent-hook.sh，以及 ~/.roamtty/claude-hooks.json（Claude Code）或启动器 ~/.roamtty/codex、~/.roamtty/grok。Codex 启动器会在 ${CODEX_HOME:-~/.codex}/config.toml 末尾追加这些 hook 的信任记录（已有同名条目则不改动）；Grok 启动器会写入 ${GROK_HOME:-~/.grok}/hooks/roamtty.json，其中的 hook 只对从应用启动的 Grok 生效。hook 把 Agent 的状态、正在执行的工具和命令、你最近一条提示词的前 200 个字符，以及 Agent 最近一次回复的前 400 个字符，保存为该 tmux 会话的选项，Agent 退出时清除；应用通过 SSH 读取这些选项，在会话列表显示。Android 版只将其保存在内存中；iOS 版还会在本机保存最近的状态摘要，保存范围与删除方式见上文。应用不会自动将这些状态发往开发者或其他接收方。这些文件留在服务器上，可随时删除 ~/.roamtty 目录、config.toml 中追加的条目和 roamtty.json；下次从应用启动 Agent 时会重新写入。不从应用启动 Agent 时不会写入这些文件。
  • 远程桌面（实验功能，默认关闭）：终端会话连上时，应用随插件检测一起只读检查这台主机有没有图形桌面（结果保存在本机的主机信息中）。你点桌面按钮后，应用才会在主机的 ~/.roamtty/ 下安装桌面插件 roamtty-desktop 和 Cisco 的 OpenH264 编码器：先由主机从 GitHub Releases（github.com/yahaa/roamtty-desktop）和 ciscobinary.openh264.org 下载，主机下载不了时由手机经 HTTPS 下载后通过 SFTP 上传，二者都按应用内固定的 SHA-256 校验。画面、光标和输入经你打开的 SSH 连接传输；主机可达时自动改走 UDP（端口 60000–61000，AES-128-GCM 加密，每次连接的随机密钥经 SSH 下发、不落盘），UDP 不通时自动回到 SSH。除上文所述的 iOS 本地桌面缩略图外，画面不写入手机存储；画面不进日志；插件日志只记录事件和统计，不记录画面、剪贴板和输入的文字。剪贴板只在你点“发送手机剪贴板 / 获取远程剪贴板”时同步。插件不监听任何 TCP 端口。在 macOS 上它是 ~/.roamtty/Roamtty Desktop.app（登录项 com.roamtty.desktop），在 Windows 上是登录计划任务“Roamtty Desktop”；可在插件页卸载，或删除 ~/.roamtty 目录将其移除。Windows 上，当你用管理员账号连接而这台 PC 没有人登录（停在登录界面）时，应用会自动安装（也可由管理员在 PC 上运行桌面页给出的命令安装）一个以 LocalSystem 运行、开机自动启动的服务 RoamttyDesktop，用来在登录界面和锁屏时也能看到画面、输入；它运行和加载的文件都在 C:\ProgramData\Roamtty 下，只有 SYSTEM 和管理员能修改，它与桌面会话之间的命名管道只允许 SYSTEM 和安装它的用户连接，并在入站防火墙中放行它自己的 UDP。以管理员身份在插件页卸载时，服务、防火墙规则和 C:\ProgramData\Roamtty 一并删除。为了断线后自动重连，桌面连接打开期间（含你设置的后台保活时间，最长 30 分钟）应用会把这台主机的密码或私钥口令留在内存中，连接关闭后即丢弃，不写入存储。
  • 应用不包含广告或第三方统计分析、崩溃上报 SDK。应用使用 AndroidX、JSch、Bouncy Castle、SwiftTerm、libssh2 和 OpenSSL 等开源组件提供界面、SSH 和加密功能；这些组件不用于向开发者收集数据。连接和文件传输发往你选择的服务器；本机诊断报告仅在你主动分享时发往你选择的接收方。

第三方服务

除上述用户主动发起的插件下载和所选择的外部链接外，应用不使用第三方服务。如果你从 Google Play 或 App Store 安装，Google 或 Apple 会依照其自身的隐私政策处理安装、购买、付款和商店相关数据（例如下载量、订单信息和你选择共享的崩溃报告），这不在本政策范围内。你连接的服务器由你或服务器管理员控制，其数据处理方式由对方负责。

网站

roamtty.com 是托管在 GitHub Pages、经 Cloudflare 分发的静态网站，不使用 Cookie、统计分析或跟踪脚本。GitHub 和 Cloudflare 作为托管与网络服务商，可能出于安全和运维目的处理访问者的 IP 地址等技术日志，适用其各自的隐私政策。

数据保留与删除

我们不持有你的任何数据，因此没有需要向我们申请删除的内容。你可以随时自行删除设备上的数据：

  • 删除主机会删除该主机配置、已保存的凭据和会话记录；服务器信任记录独立保留，可通过“重新核验”移除。
  • Android：在系统设置中清除 Roamtty 的存储空间，或卸载应用，即删除应用保存的全部本地数据。
  • iOS：卸载应用会删除应用数据和文稿目录；钥匙串中的凭据可在卸载前于应用内删除主机来移除。
  • 服务器上的 hook 文件按上文“网络连接”所述自行删除。

安全

凭据由系统密钥库保护，主机指纹变化时连接会被阻止，会话连接经 SSH、mosh 或远程桌面的加密传输保护，插件下载使用 HTTPS。如发现安全问题，请通过下方邮箱私下告知我们，不要公开披露。

儿童

本应用面向开发者与技术用户，不面向 13 岁以下儿童，也不会有意收集儿童的任何信息。

政策变更

本政策如有变更，会在本页面更新并修改生效日期。

Roamtty Privacy Policy

Effective date: 2026-10-26

Roamtty is an SSH terminal client for Android and iOS (together, “the app”). We, the Roamtty developers, run no app backend servers and require no account. We do not automatically collect or upload your personal data, and we do not sell it. When you contact support or share a report, the selected content goes to the recipient you choose. This policy covers Roamtty obtained from Google Play or the App Store, and the website roamtty.com.

Summary

  • No accounts or ads, no third-party analytics or crash-reporting SDKs, and no automatic diagnostic uploads.
  • Hosts, credentials and settings stay on your device; credentials are protected by the system keystore.
  • Terminal, file and remote desktop data goes to servers you add; desktop plugin installation may also contact the download services described below. The developers do not automatically receive your session content; contacting support or sharing a report sends the content you choose to the recipient you select.

Data stored on your device

The following data stays on your device and is used only by the app itself:

  • Hosts: name, address, port, username, authentication method, session mode, the detected remote system and whether tmux / mosh are installed.
  • Credentials: passwords are stored only when you choose to save them. An imported private key is stored when you save a host using key authentication; there is no separate option to leave the key unsaved. Key passphrases are never saved.
    • Android: passwords and private keys are encrypted with AES-256-GCM using a non-exportable Android Keystore key, and the ciphertext is stored in the local Room database.
    • iOS: passwords and private keys are stored in the system Keychain with “this device only, after first unlock” accessibility, so they never move to another device through backups or device transfer.
  • Server trust records: the server public keys and their algorithms you chose to trust, stored by server address and port. The app calculates fingerprints from these keys to detect man-in-the-middle attacks. Host entries using the same address and port share the record.
  • Session list: the ID, host, mode, title, remote tmux session name and session number of up to 8 sessions per host, used to restore the session list after the app restarts. It contains no terminal content.
  • Agent status previews (iOS): the latest agent state, tool and command details, working directory, up to 200 characters of the latest prompt and up to 400 characters of its reply are saved in local preferences to restore session cards after relaunch. Removing the corresponding session clears its previews; uninstalling the app removes its local preferences.
  • Local diagnostics (iOS): the app keeps up to 400 event-log entries and 20 iOS MetricKit metric or diagnostic reports to help investigate crashes, hangs and memory issues. These files stay on the device and are not uploaded automatically. From About, you can choose to share them with a recipient through the system share sheet. Review their contents before sharing. Uninstalling the app removes these local files.
  • Preferences: language, theme, font (including font files you import), font size, control bar and download folder settings.
  • Files you transfer (iOS): files downloaded from a server are saved in the app's Documents folder, visible and removable in the Files app under “On My iPhone › Roamtty”. Images, files and text shared to the app are held in the app's container until you upload or delete them. On Android, downloads are saved where you choose with the system file picker.

Except for the agent previews described above, terminal output, input and text drafts are kept in memory only and never written to disk. The Android app disables system backup and device transfer. The iOS app excludes its host database from iCloud and computer backups, and Keychain credentials never enter backups. Files you download into the iOS Documents folder may be included in your own device backups, like your other files.

iOS remote desktop

When remote desktop is enabled, screen frames, remote sound and keyboard/pointer actions travel between your device and the selected host over SSH or authenticated encrypted UDP, without a Roamtty relay. Sound is played back; the app does not record your phone microphone. The app saves the latest desktop frame for each host as a local JPEG thumbnail for session cards. It may contain sensitive screen content, remains after disconnection, and is removed when you delete the host or uninstall the app. These thumbnails may be included in your own device backups. Display, sound, quality and control preferences stay on your device.

Text is copied between the phone system clipboard and remote clipboard only when you tap the send or get clipboard action; the app does not continuously synchronize clipboards. The remote system and other apps with clipboard access may read their respective system clipboard.

When you choose to install or update the desktop plugin, the phone or remote computer may download the Roamtty desktop plugin from GitHub Releases and OpenH264 from Cisco over HTTPS. Those providers receive the requesting IP address and ordinary network request information under their own policies. The plugin is installed on your selected remote computer; downloaded executable code is not installed into the iOS app.

Network connections

  • Except for plugin downloads you initiate, the app connects to servers you add: SSH (TCP), mosh (UDP), encrypted remote desktop transport, and TCP reachability checks that show whether a host is online and its latency. On iOS, the system asks for Local Network permission before the app connects to a host on your local network.
  • SSH and mosh connections are encrypted; the app makes no cleartext HTTP requests (desktop plugin downloads use HTTPS only). Links you tap in the terminal open in the system browser or the matching app.
  • When connecting, the app performs read-only operations on the server: it identifies the system, checks whether tmux / mosh are available (stored in the host entry on your device), and reads the remote shell history file to suggest common commands. Common commands are cached only in the session's memory and may remain available to view after disconnecting. They are not written to persistent app storage and do not survive process termination. Host monitoring data (CPU, memory, disk, network, processes) is likewise only shown from memory. Everything else happens only when you ask for it, such as installing tmux / mosh or uploading and downloading files over SFTP.
  • When you start Claude Code, Codex or Grok from the app (except in a Windows start folder), the app writes hook files to the server so it can show the agent's status: ~/.roamtty/agent-hook.sh, plus ~/.roamtty/claude-hooks.json (Claude Code) or the launchers ~/.roamtty/codex and ~/.roamtty/grok. The Codex launcher appends trust entries for these hooks to the end of ${CODEX_HOME:-~/.codex}/config.toml (an existing entry with the same name is left alone); the Grok launcher writes ${GROK_HOME:-~/.grok}/hooks/roamtty.json, whose hooks act only for a Grok started from the app. The hooks store the agent's state, the tool and command it is running, the first 200 characters of your latest prompt and the first 400 characters of the agent's latest reply as options of that tmux session, cleared when the agent exits. The app reads them over SSH to show in the session list. Android keeps them in memory only; iOS also saves the latest status previews locally as described above. The app does not automatically send these states to the developers or other recipients. The files stay on the server; you can delete the ~/.roamtty folder, the entries appended to config.toml and roamtty.json at any time, and the next agent started from the app writes them again. None of these files are written unless you start an agent from the app.
  • Remote desktop (experimental, off by default): when a terminal session connects, the app checks read-only, along with the plugin check, whether the host has a graphical desktop (stored in the host entry on your device). Only after you tap the desktop button does the app install the desktop plugin roamtty-desktop and Cisco's OpenH264 encoder under ~/.roamtty/ on the host: the host downloads them from GitHub Releases (github.com/yahaa/roamtty-desktop) and ciscobinary.openh264.org, and when it cannot, the phone downloads them over HTTPS and uploads them over SFTP; both are checked against SHA-256 hashes fixed in the app. The picture, cursor and input travel over the SSH connection you opened, or, when the host is reachable over UDP, over UDP ports 60000–61000 encrypted with AES-128-GCM under a random per-connection key sent over SSH and never stored; when UDP fails it falls back to SSH by itself. Except for the iOS desktop thumbnails described above, the picture is not written to phone storage; screen content is not logged; the plugin's log records events and statistics only, never pixels, clipboard contents or typed text. The clipboard syncs only when you tap "Send phone clipboard" or "Get remote clipboard". The plugin listens on no TCP port. On macOS it is ~/.roamtty/Roamtty Desktop.app (login item com.roamtty.desktop), on Windows the logon task "Roamtty Desktop"; uninstall it from the plugins page, or delete ~/.roamtty on the host. On Windows, when you connect with an administrator account while nobody is signed in to the PC (it sits at the sign-in screen), the app installs (or an administrator can install it on the PC with the command the desktop page shows) the service RoamttyDesktop, which runs as LocalSystem and starts with the PC, so the sign-in and lock screens can be seen and typed into too. Everything it runs or loads lives in C:\ProgramData\Roamtty, which only SYSTEM and administrators can change; the named pipe between it and the desktop session admits only SYSTEM and the user who installed it, and an inbound firewall rule allows its own UDP. Uninstalling from the plugins page as an administrator removes the service, the firewall rule and C:\ProgramData\Roamtty. To reconnect by itself after a drop, the app keeps the host's password or key passphrase in memory while a desktop connection is open (including the background keep-alive you set, 30 minutes at most) and discards it when the connection closes; it is never written to storage.
  • The app contains no ads or third-party analytics or crash-reporting SDKs. It uses open-source components including AndroidX, JSch, Bouncy Castle, SwiftTerm, libssh2 and OpenSSL for its interface, SSH and cryptography; they are not used to collect data for the developers. Connections and file transfers go to the servers you choose. Local diagnostic reports are sent to a recipient only when you choose to share them.

Website

roamtty.com is a static website hosted on GitHub Pages and delivered through Cloudflare. It uses no cookies, analytics or tracking scripts. As hosting and network providers, GitHub and Cloudflare may process technical logs such as visitors' IP addresses for security and operations, under their own privacy policies.

Data retention and deletion

We hold none of your data, so there is nothing to ask us to delete. You can delete the data on your device at any time:

  • Deleting a host removes its configuration, saved credentials and session records. Server trust records remain stored separately and can be removed with Verify again.
  • Android: clearing Roamtty's storage in system settings, or uninstalling the app, deletes all local data stored by the app.
  • iOS: uninstalling the app deletes its data and Documents folder. To remove Keychain credentials, delete the hosts in the app before uninstalling.
  • Remove the hook files on your servers as described under “Network connections”.

Security

Credentials are protected by the system keystore, connections are blocked when a host fingerprint changes, and session connections are protected by SSH, mosh or encrypted remote desktop transport; plugin downloads use HTTPS. If you find a security issue, please report it privately to the email below rather than disclosing it publicly.
