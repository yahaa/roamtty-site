常见问题

使用 Roamtty 需要准备什么？

一台可以通过 SSH 登录的服务器，以及登录用的密码或私钥（支持 OpenSSH / PEM 格式的 Ed25519、RSA 私钥，包括加密私钥）。在主机页点 + 添加主机即可。

Roamtty 自带 AI 模型吗？

不带。Roamtty 是 SSH 客户端，Claude Code、Codex、Grok 等命令行 AI 工具需要你自行安装在服务器上并完成登录，Roamtty 负责在手机上启动并连接它们。

断线或关掉应用后，服务器上的任务还在吗？

使用 tmux 模式时还在。在主机菜单中选“安装插件”可以检测并安装 tmux；之后每个会话都对应独立的远端 tmux 会话，重新连接时自动附着。不使用 tmux 的普通 SSH 会话在断开后会结束。

mosh 连不上怎么办？

mosh 使用 UDP 端口 60000–61000，请在服务器防火墙和云服务商安全组中放行这些端口。mosh 8 秒没有回应时，Roamtty 会自动回退到 SSH。

提示“主机指纹已变化”，连接被阻止？

这可能是服务器重装或更换了密钥，也可能是中间人攻击。请先向服务器管理员确认新指纹，确认无误后在主机菜单中选择“重新核验…”。

锁屏或切到后台后连接断开？

Android：在应用设置中允许后台运行，并关闭系统对 Roamtty 的电池优化。iOS：系统会在应用进入后台一段时间后暂停其网络连接，这是系统限制；使用 tmux 模式可以让任务在服务器上继续运行，回到应用后会自动重新连接。

我的密码和私钥存在哪里？

只存在你的手机上：Android 使用 Android Keystore 加密，iOS 使用仅限本设备的钥匙串。密码只在你勾选“在本机加密保存密码”后写入，私钥口令从不保存。详见隐私政策。

如何删除我的数据？

Roamtty 没有账号，开发者不持有你的任何数据。在应用中删除主机即可删除其配置、凭据和会话记录；卸载应用会删除全部本地数据（iOS 上请在卸载前删除主机，以移除钥匙串中的凭据）。从应用启动 AI Agent 时写到服务器上的状态文件位于 ~/.roamtty，可随时删除。

Roamtty 收费吗？

免费，没有内购、订阅或广告，以 Apache-2.0 许可开源。

报告安全问题

如发现安全漏洞，请发邮件至 support@roamtty.com，标题注明 “Security”，并附上复现步骤。请在我们修复前不要公开披露。我们会确认收到并告知处理进展。
